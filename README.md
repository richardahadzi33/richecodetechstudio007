# RicheCode TechStudio

The official RicheCode TechStudio portfolio: a responsive, static website for
browsing selected web projects and getting in touch.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file
server. The site uses plain HTML, CSS, and JavaScript.

## Portfolio content

Project cards and category filters are maintained in `index.html`. The contact
form submits to the existing Formspree endpoint configured in `script.js`.
